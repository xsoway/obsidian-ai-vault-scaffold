Obsidian AI Vault Scaffold

A reusable AI knowledge-base Vault scaffold for Obsidian: standard partitioned directories, frontmatter conventions, day-to-day scripts, and scheduled automations.

$ git clone .../obsidian-ai-vault-scaffold && open in Obsidian

license MIT python 3.11+ shell bash 3.2+ for Obsidian

# Core Concepts

  • Two-digit space-prefixed partitions for ordering (00 inbox → 99 attachments); 70-System uses 70.XX-category sub-layers leaning toward docs/conventions at higher numbers.
  • Repo is a Vault: clone-and-open; scripts live in their conventional run locations; every path is injected via OBSIDIAN_VAULT_DIR with a cwd fallback.
  • Non-destructive automation: scanners report only; add-frontmatter adds without overwriting; inbox normalization is idempotent via state.json.

# Quick Start

Initialize into a fresh Vault

$ git clone https://github.com/xsoway/obsidian-ai-vault-scaffold.git
$ cd obsidian-ai-vault-scaffold
$ ./initialize.sh /path/to/your-new-vault

Use the repo directly as a Vault

$ export OBSIDIAN_VAULT_DIR=/abs/path/to/this/vault
$ python3 70-System/70.03-Scripts/scripts/new-note.py --kind learning --title "My first note"
! No hard-coded personal paths. Scripts read OBSIDIAN_VAULT_DIR, falling back to the current directory.

# Scheduled Tasks

# daily 09:00 — briefing
0 9 * * * OBSIDIAN_VAULT_DIR="$VAULT" /bin/zsh "$AUTODIR/run-daily-brief.sh"
# daily 09:05 — inbox normalization
5 9 * * * OBSIDIAN_VAULT_DIR="$VAULT" "$PYTHON" "$AUTODIR/inbox_auto_normalize.py"
# Sunday 18:00 — weekly review
0 18 * * 0 OBSIDIAN_VAULT_DIR="$VAULT" /bin/zsh "$AUTODIR/run-weekly-review-only.sh"
