03

Capabilities

▣

Standard Partitions

15 numbered areas from 00-Inbox to 99-Attachments, each with one responsibility — routing is a rule, not a habit.

◎

Frontmatter Conventions

Uniform metadata on every note — searchable, clusterable, and ready for a knowledge graph.

▸

Day-to-day Scripts

Python 3.11+ standard-library-first: new-note, add-frontmatter, html-to-md, archive-url, qmd-noise-guard.

◷

Scheduled Automations

Daily briefing, Inbox normalization, timesheets, weekly review, and P0/P1 reminders — all non-destructive and idempotent.

Ψ

LLM Wiki Subsystem

A thin 71-Wiki interface — compile, index, lint, search — delegates to a single dedicated repo, no duplication.

⌘

Parameterized, Zero Hard-coding

Every path flows through OBSIDIAN_VAULT_DIR with a cwd fallback. Clone it anywhere; it never knows your name.
